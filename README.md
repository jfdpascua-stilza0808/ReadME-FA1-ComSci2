# Distance Calculator

## Description
This program works as a calculator to solve distance.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
- x1 - Enter x1 coordinates
- y1 - Enter y1 coordinates
- x2 - Enter x2 coordinates
- y2 - Enter y2 coordinates

## Sample Output
The distance between the two points is: 7.07
